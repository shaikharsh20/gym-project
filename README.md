## 📖 About the Project

**FitZone Gym** is a static website designed for a modern fitness center. The goal of this project is to provide complete information to visitors about gym facilities, workout programs, trainers, membership fees, and contact details.

This project was built to practice core web development fundamentals learned in BCA Semester 1:
- Creating multi-page websites using semantic HTML tags.
- Linking pages using a navigation bar.
- Styling layouts, fonts, cards, and buttons with external CSS.
- Building tables, forms, and image galleries.

---

## 💻 Technologies Used

- **HTML5:** Used for the structure of each page (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<table>`, `<form>`, `<footer>`).
- **CSS3:** Used for styling, colors, layout, fonts, and hover effects (`style.css`).

---

## 📄 Pages Included

1. **Home (`index.html`):** Welcome banner, gym highlights, and key features.
2. **About Us (`about.html`):** Information about the gym, mission, and certified trainers.
3. **Programs (`programs.html`):** Training programs (Beginner, Strength, Cardio) and membership fee table.
4. **Gallery (`gallery.html`):** Photo gallery showcasing equipment, training floors, and workouts.
5. **Contact (`contact.html`):** Gym address, operating hours, and an enquiry/admission form.

---

## ✨ Key Features

- **Multi-page Navigation:** Consistent header and menu links across all pages.
- **Modern Dark Theme:** Clean layout with fitness-themed colors and typography.
- **Card Layouts:** Neatly organized highlights and trainer cards.
- **Structured Fee Table:** Easy-to-read pricing and schedule breakdown.
- **Photo Showcase:** Clear photo gallery using semantic image tags.
- **Enquiry Form:** Form with input validation for member inquiries.
- **Pure Vanilla Stack:** Fast-loading, requires no external libraries or installations.

## 🚀 How to Run the Project

1. Download or extract the project folder.
2. Open the folder `gym_website_project`.
3. Double-click on **`index.html`** or right-click and choose **Open With > Google Chrome** (or any browser).
4. Use the navigation links at the top to explore all pages!
